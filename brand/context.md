# Brand Context

## Brand
- **Name**: Presidio Web
- **Category**: Browser-native privacy engineering and PII redaction tooling
- **Description**: Private PII detection and redaction, entirely in your browser.
- **Stage**: Early public demo supporting an open-source npm/GitHub package
- **Website**: https://nacmonad.github.io/presidio-web-demo/

## Audience
- **Primary Audience**: Privacy and security engineers building internal workflows for organizations that need to use LLMs with confidential files, especially in legal and healthcare environments.
- **Secondary Audience**: Developers and regular users who need an approachable way to build or use privacy-focused applications and workflows without installing Python, configuring Presidio, or operating a separate analysis service.
- **Key Problem**: Teams need to detect and redact sensitive information before confidential documents enter an LLM workflow, but conventional Presidio setup requires technical knowledge, Python dependencies, and application integration that puts it out of reach for many users.
- **Their Language**: PII detection, redaction, data leakage, confidential files, local processing, browser-native, on-device, privacy boundary, internal workflow, LLM preprocessing, compliance, auditability, Web Worker, offline, and no upload.

## Positioning
- **Differentiation**: Presidio Web is an offline-capable, easy-to-use, near one-to-one browser port of Microsoft Presidio. Microsoft Presidio can already run locally, but typically requires Python and technical setup; Presidio Web makes the capability available through an npm package and a browser application with no local Python service to install or operate. The public site serves as an inspectable demonstration of the npm/GitHub package rather than a hosted document-processing service.
- **Competitors**: Microsoft Presidio is the primary reference and alternative. Indirect alternatives include server-hosted PII detection APIs, custom regex-based preprocessing pipelines, and general-purpose data-loss-prevention tools.
- **Market Position**: Open-source, approachable privacy infrastructure for both engineers and end users working with sensitive information.

## Brand Personality
- **Personality Words**: Calm, trustworthy, technically credible, quietly empowering
- **Tone**: Clear and professional, approachable rather than formal, serious without being alarmist
- **Voice Admires**: None specified

## Values & Mission
- **Core Values**: Privacy by architecture, technical transparency, user control, practical utility, honest claims
- **Mission**: Help organizations prepare confidential information for modern AI workflows while keeping sensitive document content under their control.

## Goals
- **Primary Goal**: Demonstrate the capabilities and privacy model of the `presidio-web` npm/GitHub package clearly enough that privacy and security engineers can evaluate it for internal workflows.
- **Key Metrics**: Demo usage, npm package adoption, GitHub engagement, documentation engagement, and successful evaluation or integration into internal workflows.
